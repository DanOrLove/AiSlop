## 🏗️ СТРУКТУРА САЙТА

### 1. Preloader (экран загрузки)
- Анимированный логотип или символ луны
- Прогресс-бар загрузки в стиле неоновой линии
- Плавное исчезновение после загрузки

### 2. Hero Section (главный экран)
- Крупный заголовок с именем (анимация появления по буквам)
- Подзаголовок с эффектом печатной машинки
- Фоновая анимация: плавающие частицы/звёзды (Canvas или Three.js)
- Кнопка "Смотреть проекты" с магнитным эффектом и свечением
- Скролл-индикатор внизу (анимированная стрелка)

### 3. About Section (обо мне)
- Двухколоночная композиция
- Слева: стилизованное фото/аватар с глитч-эффектом при наведении
- Справа: текст биографии с появлением при скролле
- Декоративные элементы: лунные фазы, геометрические фигуры
- Статистика в виде анимированных счётчиков (проекты, годы опыта, технологии)

### 4. Skills Section (навыки)
- Интерактивная сетка навыков
- Каждый навык - карточка с иконкой и прогресс-баром
- Анимация заполнения прогресс-баров при появлении в viewport
- При наведении: карточка увеличивается, появляется свечение
- Категории: Frontend, Backend, Tools, Other

### 5. Projects Section (проекты) - ЦЕНТРАЛЬНЫЙ РАЗДЕЛ
- Горизонтальный скролл секций ИЛИ вертикальный с параллаксом
- Каждая проект-карточка включает:
  * Крупное превью проекта с hover-эффектом (зум + цветовая инверсия)
  * Название проекта крупным шрифтом
  * Краткое описание с анимацией появления
  * Стек технологий в виде тегов
  * Кнопки: "GitHub", "Live Demo", "Подробнее"
  * Фоновые декоративные элементы (линии, круги, частицы)
  
- Анимации проектов:
  * Parallax эффект для изображений
  * Появление текста с задержкой (stagger)
  * Масштабирование карточек при скролле
  * Вращение декоративных элементов
  * Эффект "reveal" при появлении в viewport

### 6. Experience Section (опыт работы)
- Вертикальный таймлайн с соединительной линией
- Каждая точка таймлайна - место работы/проект
- Анимация: линия рисуется при скролле, точки появляются с пульсацией
- Карточки с информацией о позиции, компании, периоде
- При наведении: карточка подсвечивается, появляется дополнительная информация

### 7. Contact Section (контакты)
- Крупный заголовок "Давайте создадим что-то невероятное"
- Форма обратной связи с кастомными полями:
  * Имя (анимация фокуса с подсветкой)
  * Email (валидация в реальном времени)
  * Сообщение (авто-ресайз textarea)
  * Кнопка отправки с анимацией загрузки
- Социальные ссылки с иконками (GitHub, Telegram, LinkedIn, Email)
- Анимация иконок: при наведении вращение + свечение
- Фоновая анимация: медленно движущиеся частицы

### 8. Footer (подвал)
- Минималистичный дизайн
- Копирайт с текущим годом
- Ссылка на исходный код сайта
- Кнопка "Наверх" с плавным скроллом

## ✨ АНИМАЦИИ И ЭФФЕКТЫ (ОСОБОЕ ВНИМАНИЕ)

### Реализовать через GSAP + ScrollTrigger:

#### 1. Scroll-triggered анимации:
- **Fade In Up**: элементы появляются снизу с прозрачностью
- **Fade In Down**: элементы появляются сверху
- **Scale In**: элементы увеличиваются от 0.8 до 1
- **Rotate In**: элементы вращаются при появлении
- **Stagger animations**: последовательное появление списков, карточек
- **Parallax scrolling**: разные скорости для фона и контента
- **Pin sections**: закрепление секций во время анимации

#### 2. Hover эффекты:
- **Magnetic buttons**: кнопки притягиваются к курсору
- **Glow on hover**: свечение вокруг элементов
- **Text reveal**: текст проявляется при наведении
- **Image distortion**: лёгкое искажение изображений
- **Cursor custom**: кастомный курсор с инверсией цвета

#### 3. Специальные эффекты:
- **Glitch effect**: периодические глитчи на тексте/изображениях
- **Particle system**: фоновые частицы на Canvas
- **Gradient animation**: медленно меняющиеся градиенты
- **Noise overlay**: текстура шума для атмосферы
- **Vignette effect**: затемнение по краям экрана

#### 4. Переходы между секциями:
- **Smooth scroll**: инерционный скролл через Lenis
- **Section transitions**: плавные переходы с fade/mask эффектами
- **Progress indicator**: индикатор прогресса страницы сбоку

## 🎯 ПРИМЕРЫ КОДА ДЛЯ ВДОХНОВЕНИЯ

### GSAP ScrollTrigger пример:
```javascript
gsap.registerPlugin(ScrollTrigger);

// Анимация появления секции
gsap.from(".project-card", {
  scrollTrigger: {
    trigger: ".projects-section",
    start: "top 80%",
    end: "bottom 20%",
    scrub: 1,
    toggleActions: "play none none reverse"
  },
  y: 100,
  opacity: 0,
  duration: 1,
  stagger: 0.2
});

// Параллакс эффект
gsap.to(".parallax-bg", {
  scrollTrigger: {
    trigger: ".hero-section",
    start: "top top",
    end: "bottom top",
    scrub: true
  },
  y: 200,
  ease: "none"
});
```

### CSS переменные:
```css
:root {
  --color-bg-primary: #0a0a0f;
  --color-bg-secondary: #12121a;
  --color-accent-primary: #7b68ee;
  --color-accent-secondary: #9370db;
  --color-text-primary: #e0e0ff;
  --color-text-secondary: #a0a0c0;
  --gradient-main: linear-gradient(135deg, #7b68ee, #483d8b);
  --shadow-glow: 0 0 30px rgba(123, 104, 238, 0.4);
  --transition-smooth: cubic-bezier(0.4, 0, 0.2, 1);
}
